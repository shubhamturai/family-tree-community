Administrator login

The password is a browser-side administrative lock. Because this project has no server, it cannot by itself become a central authentication service. GitHub remains the actual authorization layer for writes.

First-time setup: Create the admin password for this browser. The password is stored only as a salted PBKDF2 hash in browser storage.
