Contribute to the family tree

In V1 anyone can propose a change. The proposal is opened as a GitHub Issue and is not published until an administrator approves it.

Privacy: Do not submit Aadhaar, mobile numbers, email addresses, exact home addresses, passwords, or other sensitive personal information through this public workflow.
Delete means archive from the public tree. The person's immutable ID and historical audit trail are retained. Their public record is hidden after admin approval so relationships can be safely restored later.

About this project

This is a zero-server family genealogy community. GitHub Pages hosts the public graph, GitHub Issues hold proposals, and GitHub Actions can apply administrator-approved changes.

Data principles

  • Every person has an immutable ID.
  • Relationships use IDs, never names as identity.
  • Children retain birth order.
  • Life status is derived from death information where possible.
  • Deleting a person is a reviewed archive operation, not an irreversible hard delete.
  • Sensitive identity/contact data is intentionally excluded from the public graph.
  • Changes are auditable through GitHub Issues and repository history.
